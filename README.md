# Bàn phím Pro v2

## Đã tích hợp (core + khung 50 tính năng)

### Nhóm 1 – Bộ gõ
- Telex / VNI / Tắt (🌐 chuyển nhanh)
- Gõ tắt ư/ươ, lùi dấu cơ bản
- **Fix VNI**: số 1–9 đi qua engine (trước đó bị commit thẳng → VNI hỏng)
- Auto-capitalize đầu câu
- Text expansion (dc, sdt, email…)

### Nhóm 2 – Giao diện
- Theme sáng/tối theo hệ thống
- Chiều cao bàn phím Thấp/Vừa/Cao
- Font size, hàng số, one-hand pref
- Layout QWERTY / DVORAK / COLEMAK / AZERTY

### Nhóm 3 – Phản hồi
- Haptic + chỉnh mức
- Âm thanh click (ToneGenerator)

### Nhóm 4 – Toolbar
- Select All / Copy / Paste
- Clipboard history 20 mục + ghim
- Arrow keys tùy chọn

### Nhóm 5 – Emoji & ký tự
- Emoji panel + tìm kiếm
- Kaomoji, math/currency trong panel

### Nhóm 6–7
- Incognito khi gõ password
- Long-press nguyên âm tiếng Việt
- Vuốt Space = di chuyển con trỏ
- Long-press Backspace = xóa hết
- Calculator pad trên bàn phím
- Typing counter theo ngày
- Ẩn bàn phím (nút ▼)

## Build
Push Github → Actions → tải APK.

## Bật IME
Cài APK → mở app → Bật trong Cài đặt bàn phím → chọn Bàn phím Pro.
